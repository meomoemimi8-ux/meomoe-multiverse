# 🐾 Meomoe in Multiverse

Cuốn sổ tay chính (cổng) của hệ sinh thái Meomoe — mèo con lang thang giữa đa vũ trụ,
dẫn link sang các mini-web tự học theo sở thích (vd `hanyu.meomoe.com`).

Một trang tĩnh, gói gọn trong **một file** `index.html` (không cần build).

## Xem thử trên máy
```
node serve.mjs
```
Rồi mở http://localhost:5500

## Đưa lên mạng (GitHub Pages)
- Repo này bật **GitHub Pages** (Settings → Pages → branch `main` / root).
- File `CNAME` gắn tên miền **multiverse.meomoe.com**.
- Tại nhà cung cấp tên miền `meomoe.com`, thêm bản ghi:
  `CNAME  multiverse  →  meomoemimi8-ux.github.io`

## Thêm một vũ trụ mới
Mở `index.html`, tìm `const PRO` hoặc `const HOBBIES`, thêm một dòng mèo mới.
